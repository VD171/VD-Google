# 行为准则

## 我们的承诺

作为成员、贡献者和维护者，我们承诺让每一个人参与 VD Google 社区的体验都免于骚扰，无论其年龄、体型、
可见或不可见的残疾、族裔、性征、性别认同与表达、经验水平、教育程度、社会经济地位、国籍、个人外貌、种
族、宗教，或性身份与性取向。

## 我们的标准

有助于营造积极环境的行为示例：

- 尊重不同的意见、观点和经历。
- 给予并有风度地接受建设性反馈。
- 以社区的最大利益为重。
- 对他人表现出同理心。

不可接受的行为示例：

- 挑衅（trolling）、侮辱或贬损性评论，以及人身或政治攻击。
- 公开或私下的骚扰。
- 未经明确许可公布他人的私人信息。
- 其他在专业场合中有理由被认为不恰当的行为。

## 执行

辱骂、骚扰或其他不可接受行为的实例，可以报告给维护者，邮箱为 **vd.priv8@pm.me**。所有投诉都将得到
及时、公正的审阅和调查。维护者有义务尊重任何事件举报者的隐私与安全。
