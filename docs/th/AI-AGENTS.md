# เอเจนต์ AI

VD Google เปลี่ยนบันทึกของ Google เองบนอุปกรณ์ให้เป็นสิ่งที่ **เอเจนต์ AI อ่านได้ในขั้นตอนเดียว** แทนที่จะเปิดแอปและฐานข้อมูลของ Google หลายรายการแล้วเดาความหมาย เอเจนต์จะอ่าน **ไฟล์ส่งออก** ที่มีโครงสร้างเพียงไฟล์เดียว และรู้ได้อย่างแม่นยำว่าอุปกรณ์รายงานอะไรเกี่ยวกับ RCS, Google Wallet และ Play Integrity

หน้านี้ขยายความแนวคิดที่นำเสนอใน README

## ไฟล์ส่งออก

ทั้งแอปและ WebUI สร้างไฟล์ส่งออก JSON เดียวกัน:

- **แอป**: การกระทำ **ส่งออก** จะแชร์หรือบันทึกรายงาน
- **WebUI**: การกระทำ **ส่งออก** จะเขียนไปที่ `/sdcard/Download/VDGoogle/vdgoogle-<timestamp>.json`

ทั้งสองมีสคีมาเดียวกัน เพราะแอปและ WebUI ถูกทำให้เหมือนกัน ไม่มีอะไรถูกส่งไปที่ใด: ไฟล์ส่งออกถูกเขียนบนอุปกรณ์และอยู่ที่นั่น

## ในนั้นมีอะไร

ไฟล์ส่งออกเป็นออบเจกต์ JSON เดียวที่มีคีย์ระดับบนสุดเหล่านี้:

- `app`, `version`, `exportedAt`, `timezone` - อะไรสร้างรายงานและเมื่อใด ตามเขตเวลาที่ติดป้ายของอุปกรณ์
- `device` - ผู้ผลิต รุ่น เวอร์ชัน Android และระดับ SDK
- `rcs` - ความพร้อมใช้งาน สถานะ เวอร์ชันการกำหนดค่า รายชื่อที่รองรับ สิทธิ์ของผู้ให้บริการ การแสดงตน (UCE) และการประทับเวลาที่เกี่ยวข้อง
- `wallet` - การรับรองการชำระเงิน ฮาร์ดแวร์ NFC สถานะแตะเพื่อจ่าย การยอมรับการล็อกหน้าจอ และเคยมีการเพิ่มบัตรหรือไม่
- `diagnostics` - ส่วนตรวจสอบตนเอง สร้างขึ้นสำหรับการรายงานข้อบกพร่อง

ไฟล์ส่งออกไม่มี **ข้อมูลส่วนบุคคลใด ๆ**: ไม่มีหมายเลขโทรศัพท์ ไม่มีข้อมูลรับรอง ไม่มีเนื้อหาข้อความ ไม่มีชื่อผู้ติดต่อ ทุกค่าเป็นการอ่านที่ซื่อตรง - ค่าปฏิเสธจริงยังคงเป็นปฏิเสธ แคชที่ล้าสมัยถูกติดป้ายว่าแคชไว้ ค่าที่ขาดหายไปคือไม่ทราบ

## อ่านอย่างเดียว พร้อมการกระทำที่บันทึกไว้หนึ่งอย่าง

VD Google อ่าน ข้อยกเว้นเดียวคือการกระทำทำความสะอาด (ล้างผลการรับรองที่แคชไว้ของ Google Wallet เพื่อบังคับให้ประเมินใหม่) ทุกการกระทำที่เปลี่ยนสถานะจะขอการยืนยันบนอุปกรณ์และถูกเขียนลงในบันทึกการกระทำภายในแบบ JSON เอเจนต์ที่ขับเคลื่อน WebUI เห็นการยืนยันเดียวกันและบันทึกเดียวกัน ไม่มีเส้นทางที่ซ่อนอยู่หรือไม่ได้บันทึก

## ไม่มีสัญญาเครือข่าย

VD Google ไม่เปิดเผย API เครือข่ายและไม่มีซ็อกเก็ต: มันไม่ประกาศสิทธิ์ใด ๆ เลย เอเจนต์ใช้ **ไฟล์ส่งออก** ไม่ได้เรียกบริการ นั่นคือการรับประกันความเป็นส่วนตัว ซึ่งคงไว้แม้ในการทำงานอัตโนมัติ
