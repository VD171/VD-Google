# การร่วมพัฒนา

ขอบคุณสำหรับความสนใจใน VD Google เรายินดีรับการร่วมพัฒนา ไม่ว่าจะเป็นการแปล รายงานบั๊ก
เอกสาร และโค้ด

## กฎพื้นฐาน

- **VD Google อ่านความจริงและไม่เคยปลอมอะไรเลย** การร่วมพัฒนาต้องรักษาสิ่งนั้นไว้ ค่าลบจริง
  ยังคงเป็นลบ แคชที่เก่าค้างจะถูกระบุว่าเป็นแคช ค่าที่ขาดหายไปคือ Unknown อย่าทำให้ผลการอ่าน
  นุ่มนวลลงเพื่อให้ดูดีขึ้น
- **ความเป็นส่วนตัวคือเด็ดขาด** แอปไม่ประกาศสิทธิ์ใด ๆ และ WebUI ไม่ติดต่อต้นทางระยะไกล
  อย่าเพิ่มสิทธิ์ การเรียกเครือข่าย หรือสิ่งใดก็ตามที่ส่งข้อมูลออกจากอุปกรณ์
- **แอปและ WebUI เหมือนกัน** การเปลี่ยนแปลงใด ๆ ต่อสิ่งที่แสดง หรือต่อรายงานที่ส่งออก ต้อง
  เกิดขึ้นทั้งสองที่ โดยใช้ถ้อยคำเดียวกัน ทั้งสองต้องไม่เลื่อนไหลออกจากกันเด็ดขาด
- **ป้ายกำกับมีอยู่ที่เดียว ใน 21 ภาษา** สตริงที่ผู้ใช้เห็นทุกตัวถูกนิยามไว้สำหรับแอป
  (`res/values*/strings.xml`) และ WebUI (`webroot/lang/`) หากคุณเพิ่มหรือเปลี่ยนป้ายกำกับ
  ให้อัปเดตทุกภาษา

## การแปล

การแปลเป็นการร่วมพัฒนาที่ง่ายที่สุดและมีคุณค่าที่สุด readme ถูกแปลแยกตามภาษา
(`README.<lang>.md`) สตริงของแอปและ WebUI แยกตามภาษา และเอกสารนี้อยู่ภายใต้ `docs/<lang>/`
รักษาคำศัพท์ให้สอดคล้องกันภายในแต่ละภาษา ให้เข้ากับโทนที่มีอยู่เดิม และอย่าแปลศัพท์เทคนิคที่
คุณไม่แน่ใจด้วยเครื่องแปลภาษาอัตโนมัติ

## การรายงานบั๊ก

เปิด issue พร้อมระบุรุ่นอุปกรณ์ เวอร์ชัน Android และ - หากเป็นเรื่องเกี่ยวกับผลการอ่าน - ให้แนบ
**export** (ซึ่งไม่มีข้อมูลส่วนบุคคล) ส่วนการวินิจฉัย (diagnostics) ของ export ถูกสร้างมา
เพื่อการนี้โดยเฉพาะ

## โค้ด

- บิลด์แบบ release เสมอ ไม่เคยบิลด์แบบ debug ทดสอบบนอุปกรณ์จริงที่รูทแล้ว
- อย่าใส่คอมเมนต์ในโค้ด ชื่อต่าง ๆ อธิบายเจตนาอยู่แล้ว ส่วนหัวเดียวที่มีคือแบนเนอร์ใบอนุญาต
  ที่ด้านบนของไฟล์ซอร์สแต่ละไฟล์
- ให้เข้ากับสไตล์ที่มีอยู่เดิมและทำให้การเปลี่ยนแปลงอยู่ในขอบเขตที่โฟกัส

## ใบอนุญาต

ด้วยการร่วมพัฒนา คุณตกลงว่าการร่วมพัฒนาของคุณได้รับอนุญาตภายใต้ **GNU AGPL-3.0-or-later**
ของโครงการ
