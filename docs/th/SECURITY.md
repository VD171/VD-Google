# นโยบายความปลอดภัย

VD Google เป็นเครื่องมือด้านความเป็นส่วนตัว มันทำงานในฐานะ root และอ่านสถานะที่ละเอียดอ่อน
ดังนั้นรายงานด้านความปลอดภัยจึงได้รับการพิจารณาอย่างจริงจัง

## การรายงานช่องโหว่

โปรดรายงานปัญหาด้านความปลอดภัย **เป็นการส่วนตัว** ไม่ใช่ใน issue สาธารณะ:

- อีเมล **vd.priv8@pm.me**
- อธิบายปัญหา เวอร์ชันที่ได้รับผลกระทบ และวิธีการทำซ้ำ
- หากเกี่ยวข้องกับการเปิดเผยข้อมูล ให้อธิบายประเภทของปัญหา คุณไม่จำเป็นต้องแนบ exploit ที่
  ใช้งานได้จริง

คุณจะได้รับการตอบกลับโดยเร็วที่สุด โปรดให้ระยะเวลาที่สมเหตุสมผลในการแก้ไขปัญหาก่อนการเปิดเผย
ต่อสาธารณะใด ๆ

## อะไรนับเป็นปัญหาด้านความปลอดภัย

เนื่องด้วยสิ่งที่ VD Google สัญญาไว้ สิ่งเหล่านี้จึงสำคัญเป็นพิเศษ:

- สิ่งใดก็ตามที่จะทำให้แอปเข้าถึงเครือข่าย หรือส่งข้อมูลใด ๆ ออกจากอุปกรณ์
- สิ่งใดก็ตามที่จะทำให้ข้อมูลส่วนบุคคลรั่วไหลเข้าไปใน **export** (หมายเลขโทรศัพท์ ข้อมูลรับรอง
  เนื้อหาข้อความ ชื่อผู้ติดต่อ หรือลายนิ้วมือต่อตัวตน)
- สิ่งใดก็ตามที่ทำให้การกระทำล้างข้อมูลเพียงอย่างเดียวนั้นเปลี่ยนสถานะได้โดยไม่ต้องยืนยัน หรือ
  โดยไม่ถูกบันทึก

## อะไรไม่ใช่ปัญหาด้านความปลอดภัย

- ผลการอ่านที่ดู "ผิด" แต่เป็นความจริงที่ซื่อตรง (ตัวอย่างเช่น บรรทัด RCS ฝั่งผู้ให้บริการอ่าน
  เป็น No ในขณะที่ RCS ทำงานบนแบ็กเอนด์ของ Google) ดู[คู่มือผู้ใช้](USER-GUIDE.md)
- การไม่มีคำตัดสิน Play Integrity คำตัดสินนั้นไม่ได้อยู่บนอุปกรณ์ และ VD Google จะไม่กุมันขึ้นมา

## เวอร์ชันที่รองรับ

รองรับเฉพาะเวอร์ชันล่าสุดที่ปล่อยออกมาเท่านั้น โปรดทำซ้ำบนบิลด์ล่าสุดก่อนรายงาน
