# จรรยาบรรณ

## คำมั่นสัญญาของเรา

ในฐานะสมาชิก ผู้ร่วมพัฒนา และผู้ดูแล เราขอให้คำมั่นว่าจะทำให้การมีส่วนร่วมในชุมชน VD Google
เป็นประสบการณ์ที่ปราศจากการคุกคามสำหรับทุกคน โดยไม่คำนึงถึงอายุ ขนาดร่างกาย ความพิการที่
มองเห็นหรือมองไม่เห็น ชาติพันธุ์ ลักษณะทางเพศ อัตลักษณ์และการแสดงออกทางเพศภาวะ ระดับ
ประสบการณ์ การศึกษา สถานะทางเศรษฐกิจและสังคม สัญชาติ รูปลักษณ์ส่วนบุคคล เชื้อชาติ ศาสนา
หรืออัตลักษณ์และรสนิยมทางเพศ

## มาตรฐานของเรา

ตัวอย่างพฤติกรรมที่ช่วยสร้างสภาพแวดล้อมเชิงบวก:

- เคารพในความคิดเห็น มุมมอง และประสบการณ์ที่แตกต่าง
- ให้และรับข้อเสนอแนะเชิงสร้างสรรค์อย่างมีน้ำใจ
- มุ่งเน้นสิ่งที่ดีที่สุดสำหรับชุมชน
- แสดงความเห็นอกเห็นใจต่อผู้อื่น

ตัวอย่างพฤติกรรมที่ยอมรับไม่ได้:

- การก่อกวน (trolling) ความคิดเห็นที่ดูหมิ่นหรือเหยียดหยาม และการโจมตีส่วนบุคคลหรือทาง
  การเมือง
- การคุกคามในที่สาธารณะหรือเป็นการส่วนตัว
- การเผยแพร่ข้อมูลส่วนตัวของผู้อื่นโดยไม่ได้รับอนุญาตอย่างชัดแจ้ง
- พฤติกรรมอื่น ๆ ที่พิจารณาได้อย่างสมเหตุสมผลว่าไม่เหมาะสมในสภาพแวดล้อมแบบมืออาชีพ
