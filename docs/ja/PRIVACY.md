# プライバシー

プライバシーは VD Google の機能のひとつではなく、それこそが全目的です。このページは、
アプリがあなたのデータに対して何をし、何をしないかを、あなたが検証できる平易な言葉で正確に
述べます。

## 約束

- **インターネット権限は付与されない。** アプリのマニフェストは一切の権限を宣言しません。
  インターネットも、ストレージも、連絡先も、何も。許可するものは何もありません。
- デバイスの外のいかなるファイルやサーバーにも、**何も保存、送信、伝送されない**。
- すべての読み取りは **root を通じてローカルで**行われ、デバイス上にとどまります。

## なぜ権限ではなく root が必要なのか

VD Google が説明する RCS、Wallet、アテステーションの状態は、通常のアプリからは見えない、
システム専用の保護された領域にあります。VD Google は、あなたに広範な権限を求めるのではなく、
root でそれらを読みます。root は狭く監査可能な入口であり、ランタイム権限の山は広く漏れやすい
道です。アプリは狭いほうを選びます。

## エクスポートはサニタイズされる

レポートをエクスポートするとき、VD Google は書き込む前にサニタイズします:

- **決して含まれない:** あなたの電話番号、いかなる資格情報・クッキー・トークン、メッセージの
  内容、連絡先の名前、生のケイパビリティ blob。
- **伏せ字にされる:** 長い数字の連なりや秘密のように見える値はプレースホルダーに置き換えられます。
- **診断**は構造のみ（スキーマ名、カウント、サイズ、バージョン）を運びます。名前の中に
  たまたま現れる個別の識別指紋はすべて畳み込まれて消されます。

レポートはあなたのものです。あなたが選んだ場所に書き込まれ、あなたが共有したときにのみ共有され、
あなたを特定するものは何も含みません。

## アクションは明示的で記録される

VD Google は、将来の再チェックがまっさらな状態から始まるよう、Google Wallet のキャッシュ
されたアテステーション結果を消去できます。状態を変更するいかなるアクションも:

1. まずあなたに確認を求め、
2. デバイス上のローカルな JSON ログに書き込まれます。

いかなるアクションもネットワークに到達せず、何もあなたの電話から出ていきません。

## 自分で検証する

これらすべてを鵜呑みにする必要はありません:

- ソースは公開されています: <https://github.com/VD171/VD-Google>。
- マニフェストはソースの中にあります。権限を一切宣言していないことを確認してください。
- WebUI の Content-Security-Policy はソースの中にあります。あらゆるリモートオリジンを
  ブロックしていることを確認してください。
- 同梱バイナリはチェックサム付きで[同梱バイナリ](BINARIES.md)に記載されています。
